********************************************************************************
Installation
********************************************************************************

Stable
======

Stable releases are available on PyPI and can be installed with pip.

.. code-block:: bash

    pip install ct_dlubal


Latest
======

The latest version can be installed from local source.

.. code-block:: bash

    git clone https://github.com/gramaziokohler/ct_dlubal.git
    cd compas_tna
    pip install -e .


Development
===========

To install `ct_dlubal` for development, install from local source with the "dev" requirements.

.. code-block:: bash

    git clone https://github.com/gramaziokohler/ct_dlubal.git
    cd compas_tna
    pip install -e ".[dev]"

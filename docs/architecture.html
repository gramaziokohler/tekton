Who owns what

judgment in the middle, vocabulary at the edges
compas_timber
The design model, and the structural graph that idealises it: segment splitting, node merging, mid-planes, connector segments. Tekton consumes this, never produces it.
not mechanics, units or backends
tekton_core
The structural model. Joint and plate policies, the unit contract, serialization, the assumptions report, preflight.
not one backend convention — no axis flips, no beta angles, no RFEM name strings
tekton_dlubal
RFEM and RSTAB vocabulary: protobuf objects, beta conversion, Z-down, library names, result tables.
decides nothing, translates decisions
tekton_saf
Structural Analysis Format sheets and spec conformance.
decides nothing either
tekton_app
The desktop window, and the worker command line Grasshopper shells out to.
no logic — it calls the libraries
tekton_gh
The authoring layer: twenty-three components across setup, authoring, translation, running, results and exchange.
not model building — that stays with COMPAS Timber's own components
06

Where it stands

as of 2026-09-15

Runs

  • The whole chain end to end, verified live against RFEM on 2026-09-15
  • Member forces, member and nodal deformations, support reactions read back; a failed calculation reports RFEM’s own error text
  • Results land on the beams: eleven samples per load case along the beam axis, with envelope and provenance
  • Staleness detection: every result set carries a model fingerprint
  • Push covers nodes, members, sections, hinges, surfaces, supports, cases, loads, combinations

Untested against a live solver

  • Utilization, which needs the timber design add-on and is the number designers most want
  • Plate results: surfaces are pushed, no surface table is read back yet

Missing

  • Persistent identifiers, so the engineer’s edits in RFEM survive the next push
  • Material overrides — one global grade today
  • Support types and springs — always pinned today
  • Orthotropy
  • Connection forces along a joint, the screw-design quantity
The most valuable single move, from every angle: merging the upstream branch that carries the structural graph. Until it lands, the canvas needs a dedicated Rhino environment holding a pinned revision, and it collides with the officially shipped plugin whenever both are loaded.
